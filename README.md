# Linear-Algebra-Done-Right-Solutions
Before starting college I wanted to resolidify my understanding of linear algebra, therefore I went to self study MIT's 18.700 which is their more advanced proof based linear algebra course. The course textbook was Sheldon Axler's Linear Algebra Done Right. I noticed that Jonathan Ubnoke (@jubnoske08) had done a great job writing up many solutions to the exercises (I have linked his repository below), but still there was no complete answer key. My goal is to provide sample proofs for every exercise in the book.
